# My-SQL-Server-Portfolio

This portfolio demonstrates my knowledge into the different concepts I have learnt from working with Microsoft SQL Server, and T-SQL. Folders are used for easier navigation, and begin from the most basic queries to the more advanced ones. Examples are visible in each scenario to showcase how a given faction can be used in real-life situations.

Featured Projects:
1. [View Project 1 - Stock Management](8-SQL-Scenarios/1-Stock-Management.sql)
A real-life scenario simulating a warehouse inventory system that uses tables and triggers in order to:
- Update stock levels when new deliveries are recorded;
- Track inventory changes by recording previous and new quantities in an audit table;
- Record the date and time when products are sold or restocked;

2. [View Project 2 - Customer Order Analysis](8-SQL-Scenarios/2-Customer-Order-Analysis.sql)
The analysis is designed to:
- Calculate the total number of orders, purchased quantities, and revenue for each customer;
- Identify customers meeting specific order and revenue requirements;
- Categorise customers into Status based on their total revenue;
- Retrieve customers with a specified at a time minimum revenue;
- Handle invalid revenue inputs using TRY...CATCH error handling;

* Database requirement: Before running this scenario, the database and its tables must be created using the setup scripts in the 1-Basic-SQL-Queries folder.
