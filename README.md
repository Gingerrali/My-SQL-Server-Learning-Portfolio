1. [View Project 1 - Stock Management](8-SQL-Scenarios/1-Stock-Management.sql)
A real-life scenario simulating a warehouse inventory system that uses tables and triggers in order to:
- Update stock levels when new deliveries are recorded;
- Track inventory changes by recording previous and new quantities in an audit table;
- Record the date and time when products are sold or restocked;
